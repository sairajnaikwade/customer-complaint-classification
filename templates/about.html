📌 Project Overview

The Customer Complaint Classification System is an end-to-end Natural Language Processing and Machine Learning solution designed to automatically categorize customer grievances into functional categories and route them to corresponding departments.

The system reduces manual triage latency, optimizes support team workloads, and provides transparent explainability for academic project evaluation.

🔬 NLP Preprocessing Pipeline
  1. Lowercase Conversion — Standardizes text case.
  2. Contraction Expansion — Expands phrases like wasn't → was not.
  3. Noise & Symbol Removal — Strips URLs, emails, special punctuation, and digits.
  4. Tokenization — Segments text into individual lexical tokens.
  5. Stop-word Filtering — Removes high-frequency, low-information functional words.
  6. Lemmatization — Reduces words to canonical dictionary forms via WordNet (e.g. crashing → crash).
📊 TF-IDF Feature Extraction

Term Frequency–Inverse Document Frequency transforms cleaned text into sparse n-gram feature vectors.

Parameters Used:

  • max_features = 5000
  • ngram_range = (1, 2)
  • sublinear_tf = True
  • norm = l2
